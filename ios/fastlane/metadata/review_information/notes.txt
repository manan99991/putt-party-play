No account or login is required. This review build has every tool unlocked, so no purchase is needed. The Tools tab lists every tool by category and its search finds any tool. Settings > "I run a small business" adds Business (Invoices & Quotes, 3 a month free; Business Miles; Price List).

HOW THE APP WORKS
Tenzy is a set of on-device tools plus ready-made "Build your own" tools the user can also describe in a sentence. Seven everyday tools are always free: Flashlight, QR & Wi-Fi, See & Read, Measure, Cleaner, Translate, and the Face ID Vault. The remaining tools are part of Tenzy Pro.

TENZY PRO (in-app subscription)
- A single auto-renewing subscription: "Tenzy Pro", 1 year, US$19.99, with a 3-day free trial. There is no monthly plan.
- It unlocks the Pro tools and removes the daily limits.
- The purchase screen (Settings > Go Pro, or any Pro tool's unlock screen) shows the price, 3-day trial terms, auto-renewal disclosure, and working Terms of Use (EULA) and Privacy Policy links (3.1.2).
- It can be bought in the sandbox from that screen. A real App Store install keeps Pro tools locked until purchase.

PERMISSIONS (all processed on-device; nothing is uploaded)
- Contacts: the Contacts tool finds and merges duplicates, exports a .vcf backup, and copies or moves contacts between the user's own accounts on the device. Asked only when that tool opens.
- Microphone: Audio Lab (decibel meter / tuner), Voice to Notes, Meeting Notes, Translate's voice mode and Pro Camera's video mode (sound for the clip). Audio is metered or transcribed on-device; a recording is saved only when the user taps record.
- Camera: Scan, Studio, Measure, Pro Camera, Identify, Translate (camera mode), and See & Read.
- Photos: Cleaner, Photo Studio, Privacy Scrubber and Search My Photos read photos the user selects, on-device only.
- Media & Apple Music: Animate's "Add music" lists songs on the phone that aren't copy-protected, to put under a video. Read on-device.
- Motion: the level, compass and sensors inside Measure.
- Location (when in use): compass, altitude, GPS Dashboard, parked car, Morning Summary weather (WeatherKit), travel times (Apple Maps), arrival reminders (iOS). Stays on the phone.
- Speech Recognition: Voice to Notes and Translate's voice mode transcribe speech on-device where supported.
- Background audio: Rest keeps playing sleep sounds (or listening for snoring when the user starts it) with the screen off. It runs only after the user taps start.
- Face ID: unlocks the private Vault.
- Notifications: only reminders the user turns on (medicines, birthdays, Morning Summary, parking meter, bedtime, contact backup, Price Watch, bills, warranties, tool reminders). Every one has a "Test run" button that sends a sample within seconds.
- Background: Refresh runs the user's own alerts and Price Watch (pages they added, at most 10) a few times a day. Processing, only while charging, finishes the on-device photo index for Search My Photos. Nothing else.
- Network: See & Read and the "Read the page at a link" step fetch only the page the user gives; Price Watch fetches the pages the user added. No data about the user is sent.
- Calendar: plans open the system's own event editor (EKEventEditViewController); nothing is read.

OUTSIDE THE APP: Controls (Control Center, Lock Screen, Action button) and the Shortcuts action "Save Where I Parked" (for an automation when the car's Bluetooth disconnects) open Tenzy and work in the foreground; no background location. The parking meter shows as a local Live Activity.

No ads, no advertising SDK, no IDFA, no ATT prompt. AI tools use Apple's Foundation Models on supported devices and fall back elsewhere. No data is collected; everything runs on the device.
