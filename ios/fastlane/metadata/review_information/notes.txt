No account or login is required. This review build has every tool unlocked, so no purchase is needed. The Tools tab lists every tool by category. Settings > "I run a small business" adds Business (Invoices & Quotes, 3 a month free; Business Miles; Price List).

HOW THE APP WORKS
Tenzy is a set of on-device tools plus ready-made "Build your own" tools the user can also describe in a sentence. Seven everyday tools are always free: Flashlight, QR & Wi-Fi, See & Read, Measure, Cleaner, Translate, and the Face ID Vault. The remaining tools are part of Tenzy Pro.

TENZY PRO (in-app subscription)
- Two plans in the "Tenzy Pro" group: monthly US$2.99, yearly US$29.99, each with a 7-day free trial. Both submitted with this version.
- Unlocks the Pro tools and removes daily limits.
- The purchase screen (Settings > Go Pro, or any Pro tool's unlock screen) shows the price, trial terms, auto-renewal disclosure, and Terms of Use (EULA) and Privacy Policy links (3.1.2).
- Buyable in the sandbox there; a real App Store install keeps Pro tools locked until purchase.

PERMISSIONS (all processed on-device; nothing is uploaded)
- Contacts: the Contacts tool finds and merges duplicates, exports a .vcf backup, and copies or moves contacts between the user's own accounts on the device. Asked only when that tool opens.
- Microphone: Audio Lab (meter / tuner), Voice to Notes, Meeting Notes, Translate's voice mode and Pro Camera video. Audio is metered or transcribed on-device; saved only when the user taps record.
- Camera: Scan, Studio, Measure, Pro Camera, Identify, Translate (camera mode), and See & Read.
- Photos: Cleaner, Photo Studio, Privacy Scrubber and Search My Photos read photos the user selects, on-device only.
- Media & Apple Music: Animate's "Add music" lists songs on the phone that aren't copy-protected, to put under a video. Read on-device.
- Motion: the level, compass and sensors inside Measure; telling when a drive ends for automatic parking (if switched on).
- Location (When In Use only, never Always): compass, altitude, GPS Dashboard, parked car, Morning Summary weather (WeatherKit), travel times (Apple Maps), arrival reminders (iOS). Stays on the phone.
- Speech Recognition: Voice to Notes and Translate's voice mode transcribe speech on-device where supported.
- Background audio: Rest keeps playing sleep sounds (or listening for snoring when the user starts it) with the screen off. It runs only after the user taps start.
- Face ID: unlocks the private Vault.
- Notifications: only reminders the user turns on (medicines, birthdays, Morning Summary, parking meter, bedtime, contact backup, Price Watch, bills, warranties, tool reminders). Every one has a "Test run" button that sends a sample within seconds.
- Background: Refresh runs the user's own alerts and Price Watch (pages they added, at most 10) a few times a day. Processing, only while charging, finishes the on-device photo index for Search My Photos. Nothing else.
- Network: See & Read, "Read the page at a link" and Price Watch fetch only pages the user gives. No user data is sent.
- Calendar: plans open the system's own event editor (EKEventEditViewController); nothing is read.

BACKGROUND LOCATION: only for GPS Dashboard > "Save my spot automatically", off by default. The user switches it on in the app; Tenzy then keeps a When In Use background session (CLBackgroundActivitySession, blue indicator shown). Cell-level accuracy off the road, GPS only while driving; when the user gets out, the spot is saved on the phone with a notification. Nothing is uploaded. To test: GPS Dashboard > switch on > Test run.
OUTSIDE THE APP: Controls and the Shortcuts action "Save Where I Parked" (CarPlay/Bluetooth automation) open Tenzy and work in the foreground. The parking meter is a local Live Activity.

No ads, no advertising SDK, no IDFA, no ATT prompt. AI tools use Apple's Foundation Models on supported devices and fall back elsewhere. No data is collected; everything runs on the device.
